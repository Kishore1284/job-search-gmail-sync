Privacy Policy

This policy describes how Job Search Gmail Sync handles Google user data.

Who runs this app

Job Search Gmail Sync is run by a single individual for personal use only.

Google data accessed and why

  • gmail.readonly: to find job-alert emails in Gmail.
  • gmail.modify: to apply labels to those emails.
  • gmail.compose: to send myself a daily digest.
  • calendar.readonly: to view my Google Calendar schedule.

Data handling

All processing happens locally on my own computer. No Google user data is collected, stored on any server, sold, shared with third parties, or used for advertising. OAuth tokens are stored only in a local file on my computer.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

I can revoke this app’s access at any time at https://myaccount.google.com/permissions and delete the local OAuth token file from my computer.
